# Shape Quest（奇形狀）

用身體當控制器的網頁體感跑酷遊戲，跟著提示跳躍、蹲下、跨步，或坐著轉頭、做表情，一起闖關！

🎮 **[立即遊玩](https://qqboxy.github.io/shape-quest/)**

## 遊戲重點

- **全身模式**：鏡頭辨識跳躍、蹲下與左右跨步，完成校正即可開始。
- **臉部模式**：轉頭、歪頭與表情挑戰，坐著也能玩。
- **無鏡頭模式**：電腦用方向鍵（空白鍵也能跳躍），手機在遊戲畫面上下左右滑動。
- **場景選擇**：陽光草原（60 秒），以及糖果王國的棒棒糖森林、巧克力河流、果凍軟糖城鎮、棉花糖天空（各 120 秒）。
- **挑戰規則**：成功得 100 分並補回三分之一顆愛心，失敗扣一顆；生命歸零或時間結束後結算。
- **隱私**：鏡頭影像只在裝置上處理，不上傳、不保存。

## 怎麼玩

1. 選擇冒險場景，再選「開啟鏡頭，開始冒險」或「無鏡頭開始玩」。
2. 鏡頭玩法先選全身或臉部模式，依畫面完成校正與練習。
3. 跟著提示完成動作；點「選單」或按 `Esc` 可暫停。

螢幕旋轉會保留並自動轉換校正資料；橫向校正時 Camera 放在鏡頭側，也可手動換邊。建議橫向遊玩；全身模式請保留足夠活動空間，並由家長協助固定裝置。

目前為開發原型，手部模式尚未開放；手機、平板的體感辨識與效能仍待實機驗證。

開發測試：Video Lab 提供[手動換片 PoC 說明](docs/SCENE_SWITCH_POC.md)，入口為 `?videoTest=1&sceneSwitch=1`，可驗證四個糖果場景依序切換；正式遊戲仍固定所選背景。

場景比較的「播放模式」可選「自動輪播測試」（`?videoTest=1&sceneCarousel=1`）：從所選場景開始，依序循環四個場景，可選 8／15／30 秒間隔，等目前障礙判定結束後換片。暫停不計入間隔；載入時舊片與遊戲持續進行，新片就緒後以約 0.333 秒交叉淡化，換片失敗可手動重試。每輪測試為 120 秒。

獨立[背景影片 × Canvas 道路 PoC](docs/BACKGROUND_ROAD_POC.md) 入口為 `?backgroundRoad=1`：提供四場景、橫直向預覽、影片裁切、三線道投影與測試方塊的即時控制，可儲存重現網址；未導入正式遊戲。

## 開發驗證

完整執行：`npm run test:all`（建置、單元、完整 E2E 與影片長測）。道路長測預設執行；測試範圍、分開執行方式及實機驗收項目見[測試說明](docs/TESTING.md)。
