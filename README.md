# Shape Quest（奇形狀）

用身體當控制器的網頁體感跑酷遊戲，跟著提示跳躍、蹲下、跨步，或坐著轉頭、做表情，一起闖關！

🎮 **[立即遊玩](https://qqboxy.github.io/shape-quest/)**

## 遊戲重點

- **全身模式**：鏡頭辨識跳躍、蹲下與左右跨步，完成校正即可開始。
- **臉部模式**：轉頭、歪頭與表情挑戰，坐著也能玩。
- **無鏡頭模式**：電腦用方向鍵（空白鍵也能跳躍），手機在遊戲畫面上下左右滑動。
- **三個場景**：陽光草原（60 秒）、棒棒糖森林大道與薑餅村莊（各 120 秒）。
- **挑戰規則**：成功得 100 分並補回三分之一顆愛心，失敗扣一顆；生命歸零或時間結束後結算。
- **隱私**：鏡頭影像只在裝置上處理，不上傳、不保存。

## 怎麼玩

1. 選擇冒險場景，再選「開啟鏡頭，開始冒險」或「無鏡頭開始玩」。
2. 鏡頭玩法先選全身或臉部模式，依畫面完成校正與練習。
3. 跟著提示完成動作；點「選單」或按 `Esc` 可暫停。

建議橫向遊玩；全身模式請保留足夠活動空間，並由家長協助固定裝置。

目前為開發原型，手部模式尚未開放；手機、平板的體感辨識與效能仍待實機驗證。
