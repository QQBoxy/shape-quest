## 環境與限制

本次使用本機 Node v26.8.2、Playwright Chromium；專案 engines 仍為 Node 24，沒有為本次工作改動版本要求。影片長測使用原生 1.0x 速度與真實牆鐘；一般遊戲 E2E 的可控時鐘測試不代替影片效能長測。

手機尺寸與模擬關鍵點用來驗證版面、座標轉換及狀態流程，尚未進行 iPhone Safari／Android Chrome 真人相機驗收。殘留整個 90°／180° 的影像旋轉以螢幕／影像方向事件後的關鍵點判斷；在旋轉同時大幅歪頭（超過約 45°）可能產生方向歧義，仍需實機驗證。一般 Camera 換邊只影響排版。

原片包含 AAC 音軌，播放器全部強制靜音，衍生檔沒有音軌。既有專案未提供背景音樂／遊戲音效引擎或素材，本次沒有新增音訊系統。
