# 正式原片與淡化比較

2026-11-05：舊 v2 與剪輯版已淘汰。Video Lab (`?videoTest=1`) 僅提供四個正式新場景的「原始影片＋淡化」與「原始影片」對照，不再提供 trim／xfade 剪輯版本。

淡化滑桿 0～1 秒、每格 4 影格、預設 8 影格（24 FPS 約 0.333 秒）。原片不修改；使用完整 190 影格做首尾重疊，預設輸出 182 影格、約 7.583 秒，無音軌 H.264／yuv420p／faststart。0 秒直接播放原片並強制靜音。

```sh
node scripts/prepare-candy-video.mjs --fade-presets
```
