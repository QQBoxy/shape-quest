# 原始／剪輯＋淡化比較

製作依據：[背景規格 v2.0](BACKGROUND_VIDEO_SPEC.md)（2026-11-01）。完整原片＋約 0.333 秒離線首尾交叉淡化已確認為正式製作方向；本頁仍為候選素材比較，正式遊戲預設背景整合與裝置驗收尚未完成。天空、雲層與極遠地景穩定性須依新規格另行驗收。

目前使用 **已修正為三線道的 v2 影片** `l03_candy_001_v2.mp4`，不使用舊版 v1。使用者選定的「原始影片＋淡化」是指對v2完整原片做首尾淡化，不是回到尚未修正道路的舊片。

先前淡化頁誤接舊版v1素材，並預設原程式道路參數，現已更正。原本「原規格草案／糖果影片候選校正」只改程式繪製的障礙物透視、道路格線與前進速度，並不修改影片；這組容易混淆的舊選單已移除。

頁面預設套用v2對齊參數：消失點 `(0.5,0.41)`、道路底部半寬 `0.64`、虛擬速度 `5.0`。這是依v2構圖估算的對齊值，不是保證每個AI影片影格完全符合固定透視。下方仍可手動微調，正式遊戲的共用參數不變。

唯一實驗頁為 `?videoTest=1`，預設原始＋淡化。淡化slider範圍0～1秒，每格4影格（約0.167秒），預設8影格（0.333秒）。播放中放開滑桿套用後會重新開始比較，暫停時套用則等待手動開始。

| 選項 | v2來源與處理 | 預設循環片長 |
|---|---|---:|
| 原始影片＋淡化 | 原始190影格，不做接點剪輯，首尾重疊8影格 | 182影格／7.583秒 |
| 剪輯＋淡化 | v2第17～176影格（0起算）接點剪輯，再首尾重疊8影格 | 152影格／6.333秒 |

預設淡化素材為1280×720、24fps、無音軌H.264／faststart。淡化預先合成在MP4裡，執行時維持單一HTML5 Video正常速度循環，不啟用轉場狀態機、不凍結Game Clock或調整障礙物排程。淡化可能仍有殘影或景物換位，不宣稱真正無縫。

重建當前v2素材（依序）：

```bash
node scripts/prepare-candy-video.mjs --v2
node scripts/prepare-candy-video.mjs --v2 --original-fade-only
node scripts/prepare-candy-video.mjs --v2 --fade-presets
```

滑桿素材位於 `public/videos/level-03/fades/v2-*.mp4`，0秒直接使用v2原始／剪輯來源，0.333秒使用v2預設淡化，其餘秒數使用對應的預先合成影片。沒有第二播放器、執行時編碼或後端。

其他PoC程式已移除；舊版v1影片、先前結果與研究報告保留作歷史參考，不再作為此頁來源。
