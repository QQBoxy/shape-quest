## 影片與轉場

原片皆為 1280×720、24 FPS、190 影格，影像約 7.916667 秒（容器約 7.93 秒）。部分原檔包含 AAC 音軌，所有播放器強制靜音；淡化衍生檔移除音軌。

沿用原有 FFmpeg 首尾交叉淡化，以完整原片的前後畫面重疊 8 影格（0.333 秒），輸出 `<stem>_original_xfade.mp4`：182 影格、約 7.583333 秒，H.264／yuv420p／faststart／無音軌。未額外挑接點或裁切片頭片尾。Video Lab 另保留原片對照及 0～1 秒淡化滑桿，衍生檔皆來自相同四支新版原片。

巧克力河流已使用根目錄提供的新版原片 `chocolate_river_no_black_borders.mp4`，移入既有素材路徑，並據此重建六支淡化衍生檔。

重建：

```sh
node scripts/prepare-candy-video.mjs --fade-presets
```

單片透過原生 HTML Video 循環。跨場景切換由共用 `Background.transition()` 先載入第二支影片，等待首個可顯示影格，再以約 0.333 秒透明度淡入覆蓋仍在播放的舊片；完成後釋放舊播放器。載入與淡化期間遊戲時鐘、障礙物與按鍵判定持續，失敗時保留舊片繼續遊玩並可重試。暫停與分頁隱藏仍控制兩支影片。平常只有一支背景播放器，轉場時暫時為兩支。

正式遊戲維持每局選定一景，不新增未要求的同局輪播規則。Video Lab 保留單景、手動換片、自動輪播測試（8／15／30 秒）入口。

## 畫面合成

背景影片與 Canvas 共用 16:9 畫面，等比完整顯示。Canvas 獨立繪製三線跑道，消失點 X=0.5、Y=0.45，底部兩側落於畫面左右角；障礙物與道路沿用相同投影。道路為白色半透明覆蓋與分道線，不更動原片美術，不新增糖果或棉花糖特效。除錯輔助線預設關閉。

本專案目前沒有背景音樂／遊戲音效引擎與對應素材；本次未新增或虛構音訊資源。影片播放與遊戲事件沒有時間軸耦合，未來接入音樂時可獨立持續播放。

## 螢幕旋轉與校正

- 假設旋轉前後拍攝距離不變，不要求重新校正或額外確認中立姿勢。
- 橫向採左右分欄，Camera 約六成寬度、使用工具列下方可用高度；依 Screen Orientation 的方向與角度決定鏡頭側，另提供手動換邊。直向維持上下排列。
- 相機預覽內部字圖依可用高度縮放，不再把寬度超過 600px 的手機橫向當成桌面版。
- 在相機短邊尺度下將資料轉回校正時的座標；瀏覽器已轉正的影像不重複旋轉。螢幕／影像方向更新後，僅在關鍵點仍有整個 90°／180°旋轉時補償相機 Z 軸，表情與個人化動作門檻保留。
- 校正步驟、基準與已學門檻保留；只清除未完成取樣、動作維持與平滑狀態。遊玩時短暫停止時間與判定，等待影像方向／尺寸穩定約 450ms 後自動繼續原回合。
- 單純 Camera 換邊只改排版；網址列收合等一般視窗變化不清除校正。
