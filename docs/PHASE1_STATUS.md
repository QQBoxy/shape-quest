## 已完成的程式

- Vite + TypeScript，無前端框架，Node 24.20.0，npm lockfile。
- 前鏡頭與權限／中斷處理，MediaPipe Lite 模型本機靜態供應、SHA-256 檢查及 GPU / CPU 初始化備援。
- 鏡像骨架、全身品質檢查、穩定站姿基準與左右／蹲下／跳躍逐步校正；缺資料不可通過。
- Jump、Duck、左右 Dodge，相對尺度、持續時間防抖、回正重新待命。
- 約 60 秒固定題序、3 秒預告、0.6 秒判定窗、三心、1.5 秒無敵、成功得分、結算與重開。
- 固定虛擬速度及共用透視模型，動作輪廓同步縮放，成功粒子與柔和碰撞回饋。
- 手動、失追、頁面隱藏、鏡頭中斷暫停；時鐘及無敵凍結，失追恢復後倒數及完整重新預告。
- 程式生成草原背景、候選本機影片（不保存／不上傳）、靜音／1.0x／循環／暫停同步與錯誤備援。
- 主畫面、鍵盤練習、響應式介面、全螢幕／CSS 滿版與退出、鏡頭預覽與 Debug 格線。
- GitHub Actions：PR 與 main 檢查，通過才允許 main 部署 Pages。

## 實際模組

`src/main.ts` 組裝 UI 與流程；`config.ts` 集中參數；`camera.ts` 管鏡頭生命週期；`pose.ts` 管模型與節流；`actions.ts` 提供純函式；`calibration.ts` 管校正；`game.ts` 管時鐘與規則；`renderer.ts` 管透視／骨架；`background.ts` 管影片。型別與單元測試不需實際鏡頭。

## 已知限制與 Phase 2 前事項

- Pose Landmarker 在主執行緒以目標 18 FPS 節流執行；沒有聲稱 Worker 或 60 FPS 已驗證。若實機推論阻塞或過熱，先量測再導入 Worker 或調整輸入解析度。
- 校正需要原地站姿與回中央，姿態門檻仍為初始啟發式。跳躍需髖與腳踝一同上升；遮擋或跳太快可能漏判，必須實機調校。
- Camera / Motion Profile 仍是程式背景草案，無法以目前參數宣稱 AI 影片已幾何校正。Debug 中央安全區目前為構圖參考，正式素材的禁止遮擋遮罩需依投影障礙及 UI 共同驗證。
- 執行期背景維持單一播放器；工程測試頁可比較三個離線版本，沒有多影片轉場系統。候選影片使用本機 Object URL，不會保存，16:9 比例會檢查。循環本身不重設判定時間。
- 為公平性，暫停恢復會延後未判定題目，可能使 60 秒內的題數減少；取消的題目不計失敗。
- 正式 Level 1、姿勢穿牆、Smash、動態難度、音樂音效、localStorage 與電視鏡像延遲皆未實作或未驗證，依後續階段處理。
- 尚未執行遠端部署；預期網址與維護者步驟見 [README](../README.md)。
