# 測試範圍與執行方式

## 完整自動化驗證

```sh
npm ci
npx playwright install chromium
npm run test:all
```

`test:all` 依序執行建置（含 TypeScript）、單元測試、完整 E2E 與影片整合長測。影片以 1.0x、真實牆鐘時間依序執行；整套約需 35～40 分鐘。影片與模型效能長測期間請讓測試瀏覽器保持可見，避免同時執行其他瀏覽器測試。

所有測試使用專案本機模型與素材。`test:video` 中的真人操作以合成關鍵點代替；包含兩項真正 MediaPipe 模型推論、兩種新版棒棒糖影片版本、四個糖果場景，以及手動換片／自動輪播的 120 秒回合。

| 執行方式 | 範圍 |
| --- | --- |
| `npm test` | 動作與校正、遊戲規則、臉部訊號與診斷、投影、攝影機與背景資源生命週期、追蹤器備援與節流、循環量測 |
| `npm run test:e2e` | Chromium 操作、模型初始化、手機尺寸與滑動、11 種臉部動作、暫停與重玩、場景與輪播、完整道路長測、最佳化行為 |
| `npm run test:video` | 10 項真實時間影片整合長測；獨立執行以避免效能量測互相干擾 |

道路比較測試預設執行，涵蓋四個正式糖果場景 × 橫直向，共八次至少 10 秒播放。道路功能測試同樣使用四支正式新版原片，不再提供舊片或額外 PoC 素材。

GitHub Actions 在建置與部署前執行單元測試及完整 E2E。真實時間影片長測由 `test:video` 或 `test:all` 明確執行。

## 自動化以外的驗收

目前瀏覽器自動化以桌面 Chromium 為準；行動尺寸是視窗模擬。真人動作辨識品質、手機／平板實際攝影機與效能、Safari／Firefox、電視投放，以及影片的主觀視覺品質仍需實機驗收。
