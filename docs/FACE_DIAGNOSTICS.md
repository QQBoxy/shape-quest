# 臉部 Webcam 診斷

入口 `/shape-quest/?faceTest=1`，或遊戲選單 → 進階與測試工具 → 臉部 Webcam 診斷。沿用本機 Face Landmarker，不上傳影像。正式對應及驗收見 [臉部模式](FACE_MODE.md)。

## 自然閉嘴優先驗證

1. 開鏡頭 → 自然觀看取樣。看螢幕即可，不要求正對鏡頭或刻意張眼。
2. 選「自然閉嘴巴」，原本已閉嘴也會直接開始判定，不必先做幅度學習或先張嘴。
3. 比較自然閉嘴、輕微張嘴、閉嘴微笑；觀察 jawOpen、lipGap、兩項上限與維持進度。低下顎分數但嘴唇微開不得通過，閉嘴微笑應能通過。
4. 一次確認後不會因持續閉嘴連續計數。重新選擇同一動作或按「重新確認自然閉嘴」可開始下一次測試，仍不用先張嘴。
5. 嘴唇關鍵點缺失、嘴角寬度退化或追蹤中斷不算成功，恢復時重新確認有效維持。此頁和正式遊戲共用閉嘴判斷與辨識器，不使用額外的張閉循環。

`lipGap` 是三組內唇開口的最大距離除以臉部尺度，無單位，並非牙齒咬合量測。閉合狀態 `closed` 是條件成立與否，不是相對自然表情的出力幅度，也不是成功機率。

## 其他診斷資訊

顯示鏡像 Webcam、landmarks、Pitch／Yaw／Roll、尺度、jawOpen、嘴角與上唇係數、眼睛／眉毛係數、眼瞼開度，以及原始值、自然基準、相對差值、候選與觸發／解除狀態。保留部分歷史眉部原始值供比較，但不再提供皺眉動作或將它納入遊戲判定。

其他表情與旋轉仍先記錄舒適幅度，再放鬆重做；記錄失敗保留已有門檻，不逐次降低。短暫說話、自然笑、眨眼及位置改變都應列為對照情境。

可選開始記錄 → 操作 → 停止 → 匯出 JSON。約 10Hz、最多最近 3,000 筆，含數值、基準、閉嘴上限、個人門檻與狀態，不含影像、landmarks、中心位置及裝置識別碼，關頁後清除。另記意圖、次數、誤觸、卡住狀態及舒適度；命中數不能直接當真人成功率。

```sh
npm test
npm run build
npm run test:e2e -- tests/e2e/face.spec.ts tests/e2e/face-diagnostics.spec.ts
```

合成資料及真正模型拒絕空白相機的測試，不等於一般 Webcam 或兒童真人驗收。閉合上限及容錯參數仍需不同距離、裝置、光線與玩家資料確認。
